# vive

生活存根簿 — 生活痕迹的锚点

## 项目简介

存根簿是一个"生活痕迹的存根簿"，或者说一个"关系与记忆的实体锚点"。

它既不是冷冰冰的相册网盘，也不是教条式的情绪日记。它是一个帮你把那些随时会溜走、却极具分量的生活细节，安安稳稳接住的现实容器。

**核心理念：不是帮人走出悲伤，而是给重情义的人一个落脚的地方。**

## 四个维度

| 维度 | 定位 | 说明 |
|------|------|------|
| 生活细节 | 日常细节的"冷冻库" | 记录习惯、物品、声音等现实微粒 |
| 情绪痕迹 | 情绪撕裂时的"安全缓冲垫" | 不需要冷静懂事的安全空间 |
| 连接地图 | 关系映射的"连接地图" | 厘清他人留在你身上的印记 |
| 记忆锚点 | 随时可回看的"定心丸" | 音频、文字、照片等可回看凭据 |

## 当前版本：v0.2

### 文件结构

```
life-stub/
├── index.html    # 首页 — 产品介绍与四个维度展示
├── demo.html     # 翻阅页 — 动态渲染四个维度内容
├── about.html    # 关于页 — 产品理念
├── data.js       # 数据层 — CRUD + localStorage 持久化
├── render.js     # 渲染层 — 动态渲染 + 弹窗交互
├── script.js     # 通用脚本 — 动画、导航、视差
└── style.css     # 样式 — 纸质感复古视觉
```

### v0.2 功能

- 数据层抽离：示例数据从 HTML 移至 JS 对象，由 `data.js` 管理
- CRUD 操作：支持条目的增删改查，数据持久化到 localStorage
- 多存根簿支持：可为不同的人创建独立的存根簿实例，自由切换
- 动态渲染：翻阅页内容从数据层动态生成
- 条目录入：FAB 按钮 + 弹窗表单，支持四种维度的条目添加
- 条目删除：悬停显示删除按钮，确认后删除
- 存根簿管理：改名、删除、重置为示例数据

### 使用方式

直接用浏览器打开 `life-stub/index.html` 即可。首次访问自动加载示例数据。

## 版本规划

### v0.3 — 内容录入完善
- 图片/音频上传与预览（IndexedDB）
- 日期选择器、标签管理、搜索与筛选
- 条目排序（时间线视图）

### v0.4 — 连接地图可视化
- 列表式连接地图改为可视化关系图（Canvas / SVG）
- 支持拖拽节点、自定义关系线
- 显示影响传播方向（他 → 你 → 后代）

### v0.5 — 后端 + 多端同步
- 用户账号与数据云端同步
- 隐私与权限：私密条目、分享给指定家人
- 移动端 PWA 适配，支持离线使用

### v0.6 — 情绪缓冲垫深化
- 自由书写模式（不打标签，纯倾诉）
- 情绪时间线：回顾情绪变化趋势
- 温和提醒机制（"今天有什么想记下的吗"）

### v1.0 — 闭合体验
- 数据导出（PDF 存根簿 / 时间线长图）
- 纪念日 / 节气温和提醒
- 完整 onboarding 引导
- 只读分享链接

## 设计原则

- 不做社交
- 不做鸡汤
- 不做"走出悲伤"的工具
- 始终围绕"接住"和"锚定"展开
